# F1Tenth Racing Track

This directory contains the Spielberg racing track centerline data from the [F1Tenth Racetracks] repository.

## Contents

- `Spielberg/Spielberg_centerline.csv` - Red Bull Ring (Spielberg) track centerline
  - 864 waypoints defining the racing line
  - Format: `x_m, y_m, w_tr_right_m, w_tr_left_m`
  - Scale: meters (converted to pixels at 50px/m in code)

## Source

Only the centerline CSV is included to minimize repository size.
